# Local Dictation — releases

Downloads and the auto-update feed for **Local Dictation**, a private voice-dictation app for macOS that runs
entirely on your Mac (speech recognition and cleanup are local; nothing you say leaves your computer).

**Download:** the latest `LocalDictation-<version>-share.zip` from [Releases](../../releases/latest).
Unzip, drag the app to Applications, and follow the included `README.md`.

Requires a Mac with Apple silicon and macOS 26 or newer. Installed copies update themselves; every update is
signed (EdDSA) and verified before it installs.

This repository holds release binaries only.
